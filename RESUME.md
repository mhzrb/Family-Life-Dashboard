# Resume-ready project description

## Short version

**Family Life Dashboard** — Designed and built a secure multi-user household
expense platform with live dashboards, SQL persistence, multi-currency entry,
approval-based membership, audit logging, data exports, and a Telegram bot for
button-driven expense capture.

## Technical version

Built a full-stack TypeScript household finance platform on Cloudflare Workers
and D1, featuring household-scoped authorization, member-level analytics,
Drizzle migrations, permanent Telegram webhooks, one-time account linking,
rate-limited APIs, audit logs, multilingual responsive UI, PWA support, and
CSV/JSON backup exports.

## Suggested skills line

TypeScript, React, Cloudflare Workers, D1/SQLite, Drizzle ORM, REST APIs,
Telegram Bot API, authentication and authorization, data visualization, PWA,
security hardening, CI/CD
